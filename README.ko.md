# Rack Mesh

[English](README.md) · [한국어](README.ko.md) · [日本語](README.ja.md)

Rack Mesh는 토폴로지를 작성하고 인프라 제약을 분석하는 브라우저 도구입니다.
축별 용량 한계, 장애 영향, 3D 토폴로지, 2D 및 3D 랙 배치를 보여 줍니다.

실행 사이트: https://x-mesh.github.io/headroom/

## 기능

구성도를 그리고 워크로드 조건을 정하고 장애를 주입한 뒤 먼저 한계에 닿는 축을 확인할 수 있습니다.
토폴로지 장비와 독립 장비를 2D 또는 3D 랙에 배치할 수 있습니다.
프로젝트 파일, 다이어그램, 사람이 읽는 보고서를 내보낼 수 있습니다.

계산은 브라우저 안에서 수행합니다.
프로젝트나 근거 자료를 가져오지 않으면 합성 데모 데이터를 사용합니다.

## 한계

시뮬레이터는 선언한 토폴로지, 경로, 워크로드 조건, 용량값을 계산합니다.
패킷, 큐, 수렴, 물리 장비 동작은 시뮬레이션하지 않습니다.
카탈로그 값은 참고 자료이며 실제 배포의 제조사 용량을 인증하지 않습니다.
가져온 이름과 사용자가 작성한 이름은 프로젝트 데이터이므로 자동 번역하지 않습니다.

## 로컬 실행

저장소 루트에서 로컬 서버를 실행합니다.

```sh
npm start
```

서버가 출력한 주소를 엽니다.

## 검증

전체 테스트를 실행합니다.

```sh
npm test
npm run check
npm run smoke
```

현재 스키마를 사용하며 action ID, 가져오기 형식, 내보내기 형식의 호환성을 유지합니다.
