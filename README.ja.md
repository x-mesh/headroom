# Rack Mesh

[English](README.md) · [한국어](README.ko.md) · [日本語](README.ja.md)

Rack Meshは、トポロジーを作成してインフラ制約を分析するブラウザーツールです。
軸ごとの容量上限、障害の影響、3Dトポロジー、2Dと3Dのラック配置を表示します。

公開サイト: https://x-mesh.github.io/headroom/

## 機能

トポロジーを描き、ワークロード条件を設定し、障害を注入して最初に限界へ達する軸を確認できます。
トポロジー機器と独立した機器を2Dまたは3Dラックへ配置できます。
プロジェクトファイル、図、human-readableレポートをエクスポートできます。

計算はブラウザー内で実行します。
プロジェクトや根拠データを読み込まない場合は、合成デモデータを使用します。

## 制限

シミュレーターは、定義したトポロジー、経路、ワークロード条件、容量値を評価します。
パケット、キュー、収束、物理機器の動作はシミュレーションしません。
カタログ値は参考データであり、実環境のメーカー容量を保証しません。
読み込んだ名前とユーザーが作成した名前はプロジェクトデータのため、自動翻訳しません。

## ローカル実行

リポジトリのルートでローカルサーバーを実行します。

```sh
npm start
```

サーバーが表示するアドレスを開きます。

## 検証

全テストを実行します。

```sh
npm test
npm run check
npm run smoke
```

現行スキーマを使用し、action ID、インポート形式、エクスポート形式の互換性を維持します。
